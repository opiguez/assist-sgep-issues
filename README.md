# assist-sgep — трекер ошибок и задач

Публичный трекер для ассистента **ООО «НТЦ СГЭП»**: подбор оборудования, обработка входящей почты, чат сотрудников.

Исходный код репозитория закрыт. Этот репозиторий создан только для того, чтобы сотрудники и пользователи могли **сообщать об ошибках и предлагать улучшения**.

## Как сообщить об ошибке

1. Нажми **Issues → New issue**.
2. Выбери тип: **Сообщить об ошибке** или **Предложить улучшение**.
3. Заполни форму — чем больше деталей, тем быстрее починим.

Если такого issue ещё нет, поищи по существующим — возможно, проблему уже описали.

## Что важно указать

- **Где** возникла проблема: почта (обработка письма), чат, подбор, CRM/Битрикс24.
- **Ящик** (для почтового трека) и **тема письма**.
- **Что делал** перед ошибкой (шаги).
- **Что ожидал** и **что получилось**.
- **Текст ошибки / скриншот** — дословно, без пересказа.
- **Когда** (дата/время, желательно с часовым поясом) — для поиска в логах.

## Чего не стоит присылать

- Пароли, токены, ключи, содержимое `.env`.
- Персональные данные клиентов сверх необходимого (ФИО/телефоны можно, вложения с паспортными данными — нет).
- Коммерческие тайны и цены из внутренних документов.

При сомнении — приложи минимум, а конфиденциальное опиши словами: «во вложении был файл с персональными данными».

## Что происходит дальше

Мы разбираем issue, при необходимости задаём уточняющие вопросы и отмечаем статус. Закрываем после исправления или если проблема не подтвердилась.
